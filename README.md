# CareerPath-AI

### AI-Powered Career Guidance & Personalized Learning Platform

CareerPath AI is an AI-powered career guidance platform designed to help students explore suitable career opportunities, identify their interests, and follow personalized learning paths. It transforms career goals into actionable roadmaps through assessments, learning resources, practical projects, and AI-assisted guidance.

##  Problem Statement

Many students struggle to choose the right career because they lack personalized guidance, structured learning plans, and a clear understanding of the skills required for their desired professions.

CareerPath AI addresses this challenge by combining student profiles, assessments, AI-powered recommendations, and structured learning roadmaps in one platform.

##  Key Features

- **Personalized Career Guidance:** Explore career paths based on academic background, interests, and assessment results.
- **Career Roadmaps:** Follow structured learning stages to work toward career goals.
- **Assessments and Quizzes:** Evaluate knowledge and strengthen understanding.
- **Learning Resources:** Access relevant lessons and educational materials.
- **Practical Projects:** Discover project ideas to apply skills through hands-on learning.
- **AI Career Coach:** Get AI-assisted guidance related to learning and career development.
- **Progress Tracking:** Monitor learning activities and roadmap progress.
- **Authentication:** Secure user access through Firebase Authentication.
- **Responsive Interface:** Access the platform across supported desktop and mobile screen sizes.

##  Getting Started

### Prerequisites

Make sure you have installed:
- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/fatima01asiflive-cyber/CareerPathAI.git
   ```

2. Navigate to the project directory:

   ```bash
   cd CareerPathAI
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables according to the project's configuration. Keep API keys and other secrets private; do not commit your `.env` file.

5. Start the development server using the script configured in `package.json`:

   ```bash
   npm run dev
   ```

> **Note:** If the project has separate frontend and backend directories, install dependencies and run the development scripts in the relevant directories.
